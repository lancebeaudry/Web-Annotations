Questions people ask first.

Do I need to be technical?

No. If you can follow a one-page checklist, you can run this. We practice it together until it's boring.

Which AI assistant do you set up?

Claude Code or ChatGPT Codex. If you already pay for one, we use that.

What if I don't have a staging site?

Many hosts offer one at no cost, and turning it on is part of the setup. If yours doesn't, the questionnaire tells you before you pay anything.

Does my site need to be in GitHub?

No. A repository makes undo easier and we'll set one up in your name if you want it. Without one, your host's backups are the way back.

What happens if the AI makes a bad change?

It happens on staging, where nobody sees it, and you can undo it. After the setup, reviewing and publishing changes is yours.

Can you just make the changes for me?

Yes. With hosting and support you make requests in PinPoint and we get them live. Say so in the questionnaire.
